# Freelance Management System

## Project Description

A web application designed to connect clients with freelancers and organize freelance work in one place. The platform supports three user types: **clients, freelancers, and administrators**.

Clients can publish projects and select freelancers, freelancers can find opportunities and manage their work, and administrators can oversee users and platform activity. Projects include budgets, timelines, progress tracking, and invoice records.

## User Types

- **Client:** Publishes projects, reviews applications, selects freelancers, and monitors progress and invoices.
- **Freelancer:** Finds projects, submits applications, and manages assigned work.
- **Administrator:** Manages user accounts and oversees platform activity.

## User Stories

The following user stories describe the intended functionality.

1. **As a client**, I want to create an account and sign in so that I can manage my freelance projects.
2. **As a client**, I want to publish a project with a description, budget, and start and end dates so that freelancers can understand its requirements.
3. **As a client**, I want to review applications and accept or reject freelancers so that I can select suitable people for my project.
4. **As a client**, I want to view project progress and associated invoices so that I can monitor deadlines and costs.
5. **As a freelancer**, I want to create an account and sign in so that I can access freelance opportunities.
6. **As a freelancer**, I want to browse available projects and view their requirements, budgets, and timelines so that I can find suitable work.
7. **As a freelancer**, I want to apply for projects and track my application status so that I know whether I have been selected.
8. **As a freelancer**, I want to view my assigned projects and update their progress so that clients can follow the work.
9. **As an administrator**, I want to view user accounts and activate or deactivate them so that I can manage platform access.
10. **As an administrator**, I want to review projects, applications, and invoice records so that I can oversee platform activity.
